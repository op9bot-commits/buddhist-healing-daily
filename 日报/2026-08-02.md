## ② 寺院爆品深拆｜案例：一畑山药师寺「向日葵」月替御守袋——用季节限定把到寺做成每月复访

> PR 发布于 **2026-07-29**；公开履约自 **2026-08-01** 起。相对今日运行日属**近窗履约第二日**，不是历史旧案。公开口径未见销量/GMV，故不虚构「售罄」。

### 产品、价格与热度

- **产品**：お守りづくり体験「月替わりお守り袋」第 2 弹——8 月限定「ひまわり（向日葵）」袋；用户自选御守袋、組み紐与願い紙，现场组装成「只属于自己的御守」。
- **主体**：临济宗妙心寺派·一畑山药师寺（冈崎本堂 / 名古屋别院）。
- **公开价**：**1,000 日元**（仅月替御守袋体验）；含ご祈祷与御霊泉券为 **2,000 日元**。
- **时间与场域**：接待 **9:00–16:30**（含祈祷至 15:30）；**无需预约**；设计叙事强调「向阳开放」的夏日记忆与可日常携带的沉稳观感。
- **热度口径**：官方以「人気のお守りづくり体験」与月替系列第 2 弹表述；**未见公开销量数字**，热度判断停在「可到访履约 + 季节限定」层面。

### 为什么有机会跑出来

1. **把「祈福」做成可动手的 DIY**：不是柜台上递一只成品御守，而是「选袋—选绳—写愿」，情绪价值落在制作过程本身。
2. **月替机制天然制造复访理由**：「今月はどんなお守りだろう」把一次到寺，改写成每月可期待的轻订阅。
3. **价格分层清晰**：1,000 日元接住年轻人尝鲜与伴手礼；2,000 日元把祈祷与御灵泉体验叠进同一次到访，提高客单而不换品类。
4. **双院点 + 无预约**：冈崎与名古屋并行，降低「专程奔一趟」的摩擦；与同日开卖的箔押御朱印形成「体验 + 收藏」双 SKU。

### 年轻人/中年买点

| 人群 | 买点 |
|---|---|
| 年轻访客与打卡客 | 向日葵视觉好拍、可自选配色、低决策门槛的夏日限定 |
| 中年家长/送礼者 | 可替家人写愿、价格透明、寺院正品信任 |
| 御朱印/巡礼爱好者 | 月替御守与 500 日元箔押御朱印可同日完成「体验+收藏」 |

### 商业闭环

```text
夏日情绪 / 想被祝福 → 月替向日葵御守（1,000日元）
      ↓                         ↓
现场选袋选绳写愿 → 到寺停留与内容分享
      ↓                         ↓
加购祈祷套餐（2,000）/ 箔押御朱印（各500）→ 下月新款再访
```

**闭环要点**：用季节视觉制造「现在就要来」的稀缺感，用 DIY 拉长停留，用月替与御朱印把一次性游览改成可预期回流；不把御守表述为医疗治疗。

## ⑥ 专题深拆｜超窗经典案例：菲尔·杰克逊的绩效冥想——把「觉知」嵌进团队操作系统

> 近 48 小时没有同等可复核的新冥想训练方法论发布；采用 NBA 教练菲尔·杰克逊（Phil Jackson）经典案例并标注「超窗」。其价值在于：冥想不是周边鸡汤，而是可与战术系统咬合的绩效工具。

### 方法拆解

1. **先定绩效目标，再引入冥想**：杰克逊执教公牛/湖人时期累计 **11** 冠；冥想与正念被用来让球员在高压下做「当下决策」，而不是用来宣传宗教身份。
2. **冥想服务体系，而不是替代体系**：三角进攻要求五人同时阅读防守、无私传导；冥想训练的是「一组呼吸对齐注意力」，使战术里的「一心」可被身体练习。
3. **从个人静心升级到团队同频**：公开叙述中，集体静坐与同步呼吸被用来建立非语言层面的对齐——这比单独发一段引导音频更接近「组织能力」。
4. **可迁移到情感疗愈产品的结构**：场景（高压比赛）→ 短练习（呼吸/静坐）→ 即时任务（传球/阅读防守）→ 可复盘的结果（团队执行）。文创与 App 若只有氛围词、没有「练习后立刻能做什么」，很难形成习惯闭环。

### 可对照的商业闭环（不含投放建议）

```text
高压焦虑 / 注意力涣散
  → 短时觉知练习（呼吸、静坐）
  → 立刻接回具体任务（训练、睡眠、书写愿望、佩戴闻香）
  → 用可感知反馈巩固习惯（状态稳定、团队配合、情绪切换）
  → 内容/社群/下一周期限定产品承接复访
```
