## ② 寺院爆品深拆｜案例：一畑山薬師寺 8 月箔押し限定御朱印——双神将双 SKU × ネット別院 × 月度集邮矩阵

> 主材料：爱知县一畑山薬師寺（临济宗妙心寺派）；**8/1** 开颁、**8/30** 截止（展期中，**7/31** PR TIMES 发布）。属「十二神将 IP × 箔押工艺升级 × 三渠道分发 × ネット別院远程集邮」样本。

### 产品、价格与热度

- **产品形态**：8 月限定「箔押しご朱印」共 **2 种**——大祭ご朱印「五坤神（ごこうじん）」様、十二神将ご朱印「迷企羅（めいきら）大将」様；**2026 年设计全面リニューアル**，中央金箔押印、立体华饰。
- **价格带**：各 **500 日元**（双 SKU 同价，降低选择门槛、鼓励双收）。
- **叙事锚点**：
  - **五坤神**：无縁仏供養祭意象；火·水·木·不浄·土地五神守护；8 月花火 + 莲花设计
  - **迷企羅大将**：阿弥陀如来本地佛；8 月守护神将；左右手印导悟；干支「鸡」元素
- **获取渠道（三通路）**：
  - 冈崎本堂（爱知县冈崎市）
  - 名古屋别院（名古屋市千种区春冈）
  - **ネット別院**（**2026 年新设**）——足不便者、远方信众可在线订购
- **时间稀缺**：**8/1–8/30** 月度限定；与 7 月御朱印形成连续集邮节奏。
- **销量/热度**：
  - 一畑山薬師寺以厄除け·车祓·病気平癒祈祷闻名，名古屋都市圈信众基础稳固
  - **7/31** PR TIMES 通稿当日即标注「8/1 起」开颁，御朱印情报站与 SNS 提前锁定
  - **2026 ネット別院**上线降低地理门槛，对标法岩院邮送机制但更进一步——全流程电商化

### 为什么有机会跑出来

1. **双 SKU 同价降低决策成本**：**500 日元 × 2** 比三档分层（如法岩院 500/700/1200）更易促成「一次双收」，拉高单次参拝客单。
2. **十二神将 IP 体系化**：每月轮换一位神将 + 大祭主题，把御朱印从「月度贴纸」升级为**可预测的 12 个月集邮日历**。
3. **箔押工艺溢价**：2026 设计升级金箔立体押印，在 **500 日元**价位带形成视觉差异化——比平面御朱印更具收藏与晒图价值。
4. **ネット別院焊死复购**：冈崎本堂 + 名古屋别院 + 在线商店三通路，把「必须亲赴」变为「远程也能集邮」——适合都市通勤族与御朱印深度玩家。

- 孤独感与数字隔离在超连接时代反而加剧；传统冥想 App 以「单人音频库」为主，用户常因独自练习难以坚持而放弃。
- Pinealage 解法：不做注意力竞争，而是**用技术把人导回真实世界**——帮同城用户发现、提议、加入小型线下共修圈。

### 产品框架（可复核要点）

| 维度 | 内容 |
|---|---|
| 发布 | **2026-08-10** Indiegogo 众筹启动；**7/31** 全球 iOS/Android 已上线 |
| 定位 | 线下共修匹配 App——「connect with nearby people to meditate in the real world」 |
| 四大支柱 | 共享动机、持续性、真实社交连接、集体福祉 |
| 共修场景 | 公园日落、安静广场、社区空间——非大师课，而是简单共享静默 |
| 会后机制 | 引导音频 + 会后可选择继续交流、对话或表达感谢 |
| 募资 | Indiegogo 支持开发、测试与平台上线 |
| 开发者 | Pinealage LLC（Google Play 包名 com.pinealage.app） |

### 三条可迁移机制

1. **从「内容库」到「匹配器」**：不把冥想做成无限音频货架，而是解决「谁和我一起坐」——降低坚持门槛的社交承诺比推送提醒更有效。
2. **真实连接作为差异化**：在头像与算法推荐主导的数字世界里，公园里的面对面静默成为稀缺体验——与 PETA Empathize 的「共情叙事」、ZenoWell 的「生理捷径」形成三轨互补。
3. **众筹验证需求**：Indiegogo 募资本身即社区信号测试——愿意预付的用户 = 真实共修需求的存在证明。

### 可复制的运营闭环（不含投放建议）

```text
识别孤独感/坚持困难用户（都市高压、数字隔离）
  → 同城共修匹配（公园/广场/社区空间）
  → 引导音频 + 共享静默仪式
  → 会后可选社交延续（对话/感谢）
  → 社群口碑 → 新用户匹配 → 共修频次提升
```

**边界**：线下共修面临安全审核、场地协调与参与人数波动；与 USA Archery × MaxU（**8/7** 超窗近邻）的「机构背书心智训练」分轨——Pinealage 走 C 端自发社交，MaxU 走 B 端运动协会授权。宜与超窗篮球正念 RCT（**8/3** 发表）分轨——RCT 证明的是「冥想 + 体能」协同，Pinealage 验证的是「冥想 + 社交」协同。
