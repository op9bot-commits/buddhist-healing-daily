## ② 寺院爆品深拆｜案例：高雄關帝廟「七夕緣投香袋」——限量仪式链 × 商圈满额兑换

> 上架与首发报道属 **超窗（7/23–7/24）**；活动窗口持续至 **8/19 七夕领袋**，近窗仍可作寺庙文创「稀缺规则」教科书案例。

### 产品是什么
- **形态**：客制化姻缘香袋——集漢方藥材、愛情草植花朵、武廟月老香灰与祭祀仪轨于一体；名称「緣投」兼台语「英俊」谐音与「把缘分投进来」双关。  
- **经营主体**：全台十大月老廟之一的高雄關帝廟 × 武廟觀光商圈推廣協會；并联动明星花露水、网红联盟等本地品牌。  
- **参与规则（公开口径）**：自 **7/23** 起，在商圈约 **50** 家会员店单笔消费满 **500 元（新台币）** → 扫码登「月老星君姻缘红榜」→ 七夕前夜祭祀过炉 → **8/19** 当晚到庙唱名亲领、绑红线。  
- **稀缺规则**：**限量 500 名**，额满为止、绝不追补（庙方强调制袋须凑齐时辰与因缘）。

### 爆到什么程度（数字）
- 配额硬顶：**500** 份，不追加。  
- 触发门槛：商圈 **50** 店 × 满 **500** 元消费——把「请香袋」绑成街区客流。  
- 媒体跟进：自由时报 7/23 首发后，鮮週報 7/24 确认限量 500、花露水联名与七夕兑领节点；属节庆寺庙文创的标准传播节奏。  
- 场景时间轴：登记窗（7/23 起）→ 过炉（七夕前夜）→ 唱名领袋（8/19）——**稀缺感被拉成约一个月的情绪预热**。

### 为什么爆（机制，不是玄学）
1. **限量数字可见**：500 份比「售完为止」更好传播，制造可计算的稀缺。  
2. **仪式链条完整**：消费 → 红榜 → 香灰过炉 → 唱名绑线，每一步都是内容素材。  
3. **商圈飞轮**：香袋不是货架 SKU，而是 **50 店满额兑换券**——寺庙 IP 直接给街区导流。  
4. **节气刚需切口**：七夕 / 脱单 / 桃花，比「泛祈福」更易被年轻人理解。  
5. **联名降龄**：花露水 + KOL 开箱，把月老信仰翻译成可晒的节庆物件。

### 年轻人 / 中年买点
| 人群 | 真正买单的点 |
|------|----------------|
| 年轻人（约 18–35） | 脱单叙事、限量社交货币、商圈踩点打卡、「緣投」谐音梗 |
| 中年（约 30–45） | 为子女/自己求姻缘的仪式感；满 500 元顺便完成街区消费；比高价法物更轻的祈福入口 |

### 商业闭环
```
月老 IP + 七夕节气 → 限量香袋（500）制造稀缺
        ↘ 满 500 元 × 50 店 → 商圈消费导流
        ↘ 红榜 / 过炉 / 唱名 → UGC 与媒体二次传播
        ↘ 花露水 / 烘焙供品 / 走读导览 → 本地品牌搭便车
        ↘ 8/19 到庙领袋 → 人流回流寺庙本体
```
**飞轮**：节气情绪 → 限量规则 → 街区消费 → 仪式履约 → 内容回灌下一波香客。  
**对标大陆寺庙文创**：与灵隐十八籽「三次排队」、福录香灰琉璃「名寺原料」同构——都在卖**可解释的稀缺 + 可履约的仪式**。

## ⑥ 专题深拆｜张伟丽：从「看树都是对手」到打坐自我和解

> 访谈首发与传播高峰在 **2026-07-23/24**，相对今日运行日属**超窗案例**；因近 48h 无更新的同等强度名人方法论，且与近窗「绩效冥想 / AI 冥想」主题互证，故作专题深拆并标注超窗。

### 她是谁（背景）
- UFC 草量级冠军张伟丽；2022 年失金腰带后经历约大半年严重内耗。  
- 2026 年 7 月《热浪之外2026》与陈鲁豫对谈，复盘低谷期的睡眠、训练与心理状态。

### 低谷有多具体（数字与事实）
- 内耗周期：约 **大半年**。  
- 睡眠：**一天只睡约 4 小时**；白天仍训练 **6–7 小时**，常一边哭一边练。  
- 认知扭曲：「看树都觉得是对手」——把生活场景全部对抗化。  
- 主动求助：向教练坦白需要心理老师，备战期间接受辅导；后发现「真正走出来还是需要自己跟自己和解」。

### 她具体怎么练（可复述的操作）
1. **打坐观察**：观察一呼一吸、念头升起，不再对抗负面情绪，而是旁观与接纳。  
2. **身体对话**：训练中给自己正向鼓励，而不是用对抗心态压榨身体。  
3. **通感练习**：换视角看天空、云、树，感受「跟草也是一体」。  
4. **结果降权**：从「一定要击败谁」转向「够到自己的极限」；太在意结果时结果反而成负担。  
5. **毕业动作**：对心理老师说「我不需要心理课了」——以自主冥想承接专业辅导。

### 与赛道的互证
- **近窗**：SereneAI 等产品把「个性化引导」产品化——张伟丽案例证明高端用户要的是**可内化的自我调节技术**，不是永远外包给咨询师。  
- **超窗学术**：篮球正念 RCT、英格兰队图赫尔训练——运动绩效冥想已成跨项目叙事。  
- **内容钩子**：  
  - 「UFC 冠军一天睡四小时时，靠打坐结束了心理课」  
  - 「从看树都是对手，到把八角笼化为自己的一部分」  
  - 「合香珠日销过万的同一周，冠军在教你观察呼吸」

### 模式抽象
```
高压竞技失利 → 睡眠崩溃 / 过度对抗 → 心理辅导（外援）
        ↘ 打坐冥想（内观技术）→ 自我和解 → 绩效心态稳态
```
与 App 订阅、寺庙香袋、合香手串同构：**都在出售「把失控感按暂停」的技术或物件。**
